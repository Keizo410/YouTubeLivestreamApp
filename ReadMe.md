## 🚀 Quick Start

> requires: .env for __frontend__/ and __backend__/


```bash
git clone https://github.com/Keizo410/YouTubeLivestreamApp.git
# for backend 
cd YouTubeLivestreamApp/backend
docker-compose up -d
# for frontend use web option 
cd ../frontend
npm install 
npm start 
```
